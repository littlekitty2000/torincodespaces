# Tor, but in Codespaces
###### rather CPU heavy.

This is intended for Codespaces but can probably be used in normal Ubuntu idk

How to install dependencies:
-
Run ```git clone https://github.com/littlekitty2000/torincodespaces.git && cd torincodespaces``` in the terminal to clone this repo And change the directory to said repo.
Now run ```. install.sh``` cuts its head of- I mean run it. (install.sh is pretty much all the dependencies), also at the end you might wanna click either y or n to make an alias.

How to run:
-
It doesn't take a genius to realise that to run a python script you use python.
If you don't have Python3 installed run ```sudo apt update && sudo apt install python3``` then ```python3 main.py```
If you have Python3 installed just run the latter.
Although if you chose to make as alias just run ```cstor```
Oh yeah then you click "Ports", find "8080", hover over it, and click the "🌐" ass symbol to open it in a new page.

How to stop
-
Use either ctrl+c or type ```stop``` and hit enter
